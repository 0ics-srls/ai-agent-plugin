# ai-agent — a plugin of the ai-agent catalogue

**v2.31.53** — The whole ai-agent set: it installs the plugins dev, biz and info.

It has no command of its own: installing it installs the plugins `dev` (software development), `biz` (the funnel of the startup ideas) and `info` (research verified), each of which can then be enabled or disabled by itself, for the machine or for one project.

Install: `claude plugin marketplace add 0ics-srls/ai-agent-plugin`, then `claude plugin install ai-agent@ai-agent`. How it
works, with the diagrams of which command comes when: https://github.com/0ics-srls/ai-agent-plugin/blob/master/FLOW.md —
how to update, what the plugin writes in a project and the other plugins of the catalogue are in the
repository's README: https://github.com/0ics-srls/ai-agent-plugin
