# info — a plugin of the ai-agent catalogue

**v2.31.55** — Research verified (info-*): search, cross-reference, audit, report.

Start with `/info:info-help`: facts are gathered with their sources, cross-referenced against independent ones, audited for reliability and bias, and reported with a confidence level each. It writes its documents in the project's folder and needs no setup.

Install: `claude plugin marketplace add 0ics-srls/ai-agent-plugin`, then `claude plugin install info@ai-agent`. How it
works, with the diagrams of which command comes when: https://github.com/0ics-srls/ai-agent-plugin/blob/master/FLOW.md —
how to update, what the plugin writes in a project and the other plugins of the catalogue are in the
repository's README: https://github.com/0ics-srls/ai-agent-plugin
